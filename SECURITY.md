# Security policy

## Reporting a vulnerability

Please do not report security issues in public issues, pull requests or discussions.

Report them privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**, or go straight to
[the private reporting form](https://github.com/nevzheng/mammoth-cache/security/advisories/new).
Include what you found, how to reproduce it, and the impact you expect. You will get an
acknowledgement, and we will keep you updated as we work on a fix.

## Supported versions

mammoth-cache is pre-1.0. Only the latest `main` receives security fixes.
